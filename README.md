# Green Life — сайт-галерея

Сайт компании Green Life (озеленение и благоустройство, питомник растений, Новосибирск).
Статический сайт без сервера, публикуется через GitHub Pages.

## Что где лежит

| Путь | Что это |
|---|---|
| `src/catalog.mjs` | **Весь контент**: главы, растения, сорта, тексты, цены, контакты, отзывы |
| `src/build.mjs` | Сборка: превращает каталог в `index.html` |
| `index.html` | Готовая страница (создаётся сборкой, руками не править) |
| `css/main.css` | Стили |
| `js/main.js` | Анимации и поведение страницы |
| `js/diag.js` | Панель диагностики для проверки на телефоне (только по адресу с `?diag=1`) |
| `js/grow.js` | «Рост» SVG-растений |
| `js/deco/*.js` | Растения по бокам экрана для каждой главы |
| `img/` | Фотографии (WebP) |
| `fonts/`, `vendor/` | Шрифты и библиотеки анимации — локально, без внешних CDN |

## Как поменять цену, текст или добавить растение

1. Открыть `src/catalog.mjs` и поправить нужное место. Цена задаётся так:
   - `price: { from: 1200 }` — на сайте будет «от 1 200 ₽»
   - `price: { value: 1200 }` — «1 200 ₽»
   - `price: null` — «по запросу»
2. Пересобрать страницу (нужен Node.js 18+):
   ```bash
   node src/build.mjs
   ```
3. Проверить локально:
   ```bash
   python -m http.server 8765
   ```
   и открыть http://127.0.0.1:8765/
4. Отправить изменения на GitHub — сайт обновится сам через минуту-две.

Новая фотография: положить в `img/` в формате WebP (до ~1600 px по большей стороне)
и указать её в `catalog.mjs` вместе с шириной и высотой.

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub и загрузить в него содержимое этой папки.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`.
3. Через пару минут сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
4. Свой домен (например, `greenlife-nsk.ru`) подключается там же, в поле **Custom domain**.

## После публикации (поиск и соцсети)

1. Вписать адрес сайта в `src/catalog.mjs` → `company.siteUrl` (например `https://greenlife54.ru/`)
   и пересобрать: появятся `robots.txt`, `sitemap.xml`, канонический адрес и правильные превью ссылок
   в WhatsApp, Telegram и VK.
2. Лучше подключить свой домен `.ru`: для сайта на `github.io/<репозиторий>/` Яндекс хуже определяет регион,
   и robots.txt там не работает.
3. Яндекс Вебмастер: добавить сайт, подтвердить, отправить `sitemap.xml`, указать регион «Новосибирск».
4. Яндекс Бизнес и 2ГИС: карточка организации с тем же названием и телефоном и ссылкой на сайт.
5. Яндекс Метрика (по желанию): прислать номер счётчика — добавим код и цели на кнопки WhatsApp и звонка.
   Перед этим нужна страница политики конфиденциальности (152-ФЗ).

Сезонные предложения (подсветка к Новому году, бронь на весну) лежат в `promos` в `catalog.mjs`
и пропадают после даты `until` (на странице — сразу, из кода — при следующей сборке).

## Анимации

- Плавный скролл — Lenis; сценарий — GSAP (ScrollTrigger, SplitText, DrawSVG).
- Для посетителей с включённой настройкой «уменьшить движение» анимации отключаются,
  контент показывается сразу.
- Первый экран — только «Green Life» крупно и подзаголовок «Благоустройство и озеленение · высшего качества»
  (`hero()` в `src/build.mjs`; фон и слово на холсте, на телефоне стоймя слово идёт двумя строками).
  Трава и полевые цветы на буквах прорастают сами; при прокрутке титул растворяется, дальше идёт вступление
  (`intro()`: чем занимаемся, кнопки, телефон) и первая глава. Тексты вступления — в `intro()`.
  Размер слова задаёт CSS (`--fs` у `.hero-title` в `css/main.css`): запасной текст (пока холст готовится и без скриптов)
  и холст получают один размер и одно место, поэтому слово не прыгает. Заливка букв — `img/tex-hedge.webp`
  (`tex-hedge-s.webp` — уменьшенная, для телефона): середина фото живой изгороди без лавочки и без тёмных краёв,
  широкая картинка примерно 2,6 : 1; подойдёт любая другая такого вида. Превью ссылок в мессенджерах — `img/og-hero.jpg`
  (снимок первого экрана 1200×630; после смены вида титула его стоит переснять).
- Растения по бокам подгружаются только когда посетитель подходит к главе.
- Браузеры, которые открывают ролики в своём плеере поверх страницы (Mi Браузер, Huawei, UC, QQ и похожие),
  получают кадры роликов на холсте — плеера нет. Проверить такой показ в любом браузере: адрес с `?canvas=1`
  (выключить — `?canvas=0`).
- Если на каком-то телефоне сайт «стоит» (нет роликов или движения текста), откройте адрес с `?diag=1`
  и пришлите снимок экрана: панель внизу слева покажет браузер, режим роликов, отказы запуска, ошибки и частоту кадров.
